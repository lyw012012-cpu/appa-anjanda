# I-13 시뮬레이션: 무작위 돌리기 대 이 모델

**시뮬레이션 가정 안에서의 결과이고 효과의 증거가 아닙니다.** 반응 모델의 값(깨는 확률 식의 계수, 스누즈·다시 잠듦 확률)은 모두 [가설]이며 `out/results.json`의 `meta.assumptions`에 적혀 있습니다.

## 실행

```bash
cd app
npx jest sim          # planAlarm·fitBandit·computeStats를 그대로 불러 out/results.json을 씀 (결정적, 약 20초)
python sim/plot.py    # results.json만 읽어 그림 2장과 summary.md를 만듦. 추천을 다시 구현하지 않음
```

## 무엇을 돌렸나

- 가상 사용자 5종(①잠이 깊음 ②얕음 ③늘 스누즈 ⑥고음이 안 들림 ⑦예민함) × 14일(하루 한 번 07:00) × 20회 반복. 소리를 안 고른 사람(`chosen` 빔)으로 시작.
- 단계마다 깨는 확률 = σ(base + w단계·단계위치 + w습관·pHabit + w520·sim520 + w음높이·pitch). 습관화(pHabit)는 앱과 같은 `computeStats`(진짜 소리 30개)로 계산합니다. 즉 "습관화 식이 맞다"고 가정한 세계입니다.
- 비교군: 무작위(같은 3단계 틀, 소리만 무작위, 빼기·거슬림 상한은 지킴) / 학습 없는 규칙(`priorVar` 1e-9) / 이 모델 / `hand` 특징 없음(모든 소리의 520 닮음을 0으로) / 대비를 음높이·거칠기 축으로 잰 **근사**.
- 같은 사용자·같은 반복에서는 깨기 판정 난수를 비교군끼리 공유합니다(공통 난수).

## 결론 (시뮬레이션 가정 안에서)

사전에 정한 기준(무작위보다 안전장치 비율과 깬 단계 평균이 낮은가)은 5종 모두에서 만족했습니다. 안전장치 비율은 ①69→53% ②0.4→0% ③46→24% ⑥44→25% ⑦7.5→1.8%이고, 깬 단계 평균도 모두 낮았습니다. 다만 이 차이의 대부분은 **학습이 아니라 사전 규칙**(익숙한 소리 피하기, 대비 고르기)에서 옵니다. "학습 없는 규칙"과 비교하면 이 모델이 뚜렷이 나은 유형은 ⑥ 하나(안전장치 39→25%, 깬 단계 2.93→2.54)이고, 나머지 유형은 14일 안에는 차이가 반복 간 표준편차 안입니다. ⑥에서는 음높이 가중치가 첫날 −0.07에서 14일째 −0.24까지 음수로 더 내려가 "고음에 못 깬다"를 배웠고(정답 방향 코사인 0.75→0.90), 이는 설계가 노린 "개인화가 가장 효과 있는 경우"와 일치합니다. 팀 기록(3명 × 며칠)에서는 가중치가 사전값 근처에 머문다는 한계 서술과 같은 방향입니다.

- `hand` 특징: 이 시뮬레이션에서는 있고 없고의 깬 단계 차이가 반복 간 오차 안입니다(⑥ 2.54 vs 2.50). 정답 가중치에 520 항이 있는 유형에서 코사인만 조금 높습니다. 근거가 약하므로 지금은 유지하고, 실제 기록이 쌓이면 다시 봅니다.
- 대비 방법: 음높이·거칠기 축 근사는 모든 유형에서 임베딩 거리보다 나빴습니다. 다만 이 근사는 습관화 일반화 범위까지 같이 바꿔(남은 낯선 소리 14.7 vs 28.3) 공정한 비교가 아닙니다. "임베딩 거리가 낫다"는 결론이 아니라 "이 근사로는 낫다는 근거가 없다"입니다.
- C9 값은 바꾸지 않았습니다. 바꿀 만한 근거가 나온 값이 없습니다.
- 한계: 반응 모델이 설계와 같은 습관화 식·같은 특징 5개로 만들어져 모델에 유리한 세계입니다. 실제 사람 반응과 다르면 결과도 달라집니다.
