# 설계·점검 체크리스트

> 설계·문서·규칙을 쓰거나 "됐다"고 말하기 전에 해당하는 절만 훑는다. 각 항목의 "사례"는 이 프로젝트에서 실제로 생긴 허점이다 (PR #4).
> 새 허점이 나오면 한 줄 추가한다. 같은 실수가 두 번 나오면 가능하면 도구(ESLint·검사)로 옮긴다 ([architecture/](../architecture/README.md)).

## A. 설계·문서를 쓸 때

- [ ] **이름·값·경로를 옮겨 적지 않았다.** 링크로 가리키고, 꼭 적어야 하면 원본(contracts)을 열어 대조했다.
  사례: AGENTS.md에 설정값을 `K`·`W`·`T_max`로 적었는데 contracts C9의 실제 이름과 달랐다.
- [ ] **확정 아닌 것을 사실처럼 쓰지 않았다.** `[권장]`·`[초안]`·`[미확인]`·`[가설]` 표시를 그대로 가져왔다.
  사례: AI 개념 설계가 진행 중인데 개요에 "YAMNet 임베딩"을 결정처럼 적었다.
- [ ] **새 규칙이 계약·설계와 부딪히지 않는지 검색했다.** 관련 단어로 `docs/context/`를 찾아봤다.
  사례: "오디오 파일 커밋 금지"를 썼는데 contracts C3은 `app/assets/sounds/`를 커밋한다.
- [ ] **핵심 기능이 플랫폼에서 되는지 공식 문서로 먼저 확인했다.** 확인 못 했으면 `[미확인]`과 확인할 이슈를 적었다.
  사례: Expo Go로 확인하면 된다고 했지만, 직접 넣은 알림 소리는 Expo Go에서 안 된다(R1, Expo Notifications 문서).

## B. 규칙·검사를 만들 때 (ESLint, 로더 검사, 테스트)

- [ ] **막아야 할 것을 우회 경로까지 시험했다.** 별칭(`@/lib/x`)과 상대 경로(`./x`, `../x`), 같은 일을 하는 다른 API를 모두 넣었다.
  사례: M2가 `@/lib/alarm`만 막아서 `./alarm`, `new Date()`, `performance.now()`가 통과했다.
- [ ] **허용돼야 할 것도 시험했다.** 정상 코드가 걸리지 않는지 확인했다(`./sound-library`, `new Date('2026-…')`).
- [ ] **시험을 레포에 남겼다.** 임시 파일로만 확인하고 지우면 나중에 규칙이 깨져도 모른다.
- [ ] **확정 안 된 결정을 규칙으로 박을 때 근거와 상태를 적었다.** 대상 파일이 아직 없으면 그 이름의 근거(계약 절)를 적었다. 이름이 바뀌면 규칙이 오류 없이 아무것도 안 하게 된다.

## C. "됐다"고 말할 때

- [ ] **어디까지 확인했는지 단계를 밝혔다.** 타입·린트 / 번들 / 휴대폰 실행 / 서버(Firebase·EAS) 연결 / 기능 동작은 서로 다른 단계다.
  사례: 타입 검사와 번들만 되는데 "앱 개발 환경은 갖췄다"고 했다. Firebase·EAS·휴대폰 실행은 없었다.
- [ ] **확인 못 한 것을 같이 적었다.** 빈 앱에서 `npm run check`가 통과한 것은 기능이 맞다는 증거가 아니다.
- [ ] **완료 조건이 가리키는 기준이 확정돼 있다.** 초안 이슈, 아직 없는 테스트를 기준으로 "완료"라고 하지 않았다.

## D. 함께 쓰는 파일을 바꿀 때

- [ ] **팀원이 쓴 문서나 공용 파일(CLAUDE.md, contracts.md)은 바꾸기 전에 물었다.** 바꿨으면 PR 설명에 이유를 적었다.
- [ ] **계약을 바꾸는 일이면 코드보다 먼저 `docs(contract):` PR을 올렸다** (contracts 9절).

## E. 환경과 명령

- [ ] **환경을 가정하지 않고 확인했다.** 실행 명령(`python`과 `py`), 버전, `.env`, 설치 여부를 실제로 쳐 봤다.
  사례: 이 PC는 `python`이 없고 `py`(3.14)만 있었다. `features.py`가 설계와 다른 MFCC인 것도 늦게 알았다.
- [ ] **이어 붙인 명령이 중간에 실패하면 멈추는지 확인했다** (`&&`). 커밋 전에 `git status`로 올라갈 파일을 봤다.
  사례: 첫 커밋이 실패했는데 다음 `git add -A`가 실행돼, 나눠 둔 커밋 준비가 섞였다.
